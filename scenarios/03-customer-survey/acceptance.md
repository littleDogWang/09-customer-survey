# 客户反馈调查验收标准

## 必须通过

- Agent 按顺序提问并能识别有效答案。
- 用户跳过非必答题时，结果中保留未回答状态。
- 用户中途结束时，已确认答案仍能保存。
- 完成问卷后只生成一份结果，重复提交不会产生重复记录。
- 结果包含完成状态和跟进标记，不能只依赖 transcript 推断。
- 结果保存失败时，Agent/前端明确显示失败，不声称已保存。

## 推荐用例

1. 完整回答所有问题。
2. 跳过一个非必答问题。
3. 在第三题后结束。
4. 网络失败后重复提交同一会话。
5. 负面反馈触发 `follow_up_required=true`。

## 证据

- 结果 JSON/SQLite 记录。
- 对应 session transcript。
- 重复提交前后记录数和状态。
- 结果 API 合同测试。
